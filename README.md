# AISSAI Accelerator Hackathon 2026

Welcome! This repository is the working space for the **AI for Particle Accelerators Hackathon**, organized by GANIL as part of the AISSAI / M4CAST initiative.

- **Dates:** October 11–16, 2026 (arrival Sunday evening, closing Friday afternoon)
- **Venue:** Les Domaines de Gaston, Normandy, France
- **Participants:** ~30, from CERN, ESS, KEK, BNL, IJCLab, ARRONAX, and other institutions worldwide

🚧 This repository is under active construction. Placeholders (`TBD`) will be filled in progressively before the event.

## Repository structure

```
.
├── lectures/       Introductory lectures (Monday morning) — one folder per lecture
├── challenges/      The 3 hackathon challenges — one folder per challenge
└── coding-assistant/ A coding model served on DALIA, for Claude Code or any OpenAI client
```

## Week overview

- **Sunday:** Arrival, welcome dinner
- **Monday:** Introductory lectures, challenge presentations, team formation, environment setup
- **Tuesday–Thursday:** Team work on your challenge (Wednesday afternoon free)
- **Friday morning:** Final presentations, closing

See each challenge folder for its specific objectives and starter material.

## Getting started

Each challenge folder is self-contained and includes:
- `README.md` — challenge description and case holder(s)
- `scientific_case.md` — background and motivation
- `objectives.md` — easy / medium / hard objectives (bullet points only)
- `requirements.txt` — Python dependencies
- `kickoff_notebook.ipynb` — a starter notebook to get you going
- `data/` — dataset description, ontologies/schemas

See the **[Participant Access Guide](access-guide.md)** for everything you need to set up before the event: GitHub, Agora chat, CC-IN2P3, eDARI, and DALIA @ IDRIS compute access. Start those steps as early as possible — some require approval and can take a few days.

See **[GRADING.md](GRADING.md)** for how objectives are scored and logged to Weights & Biases.

See **[coding-assistant/](coding-assistant/)** to use the coding model that runs on DALIA from Claude Code on your laptop.
